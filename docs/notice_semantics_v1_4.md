# 通知时间及受众规范化1.4

本轮不改原始摘录schema，原文引文仍逐字校验。规范化fixed候选可只有fixed_start_at而fixed_end_at为空；只有结束没有开始仍被前端拒绝，缺结束仍不能确认或用于固定占用计算。前端版本2026.10.27.1对应这一扩展。

裸日号只接受显式reference_date的所属年月，日期早于参照日不自动滚月；同分句另有日期时保守要求补全归属。楼室编号不按日号处理。显式日期后括号星期须与日历一致。截止界限不能因fixed标签而直接变成活动开始。

角色职责来自行动引文时逐项提示；通知整体另有指定角色或参加范围时以整体提醒保留，不自动判断用户身份，不设置must_do或priority。全局提醒数量有边界，超出时要求分段，不静默截断为完整成功。

review_user_notices.py是与合成评测器分开的明确发送入口：默认只校验输入，不联网；只有--send-to-configured-model才发送已提供的user_provided资料。草稿来源为pasted_notice，不能伪装成synthetic。该入口不打开报名链接、不写用户浏览器；结果仅采集供人工语义审阅，没有自动准确率分数。完整资料输出应放任务work等非代码仓库位置。

默认合成回归使用notice-challenges.v2.json，v1保持历史冻结。v2仅将N11改为要求保留已知开始。相关例题和模式测试均不是独立准确率。当前代码服务版本1.4，已有运行进程需重启才能加载。
