# 具体排程 v1（后端1.5，本地代码）

`POST /api/v2/plan`直接接受v2确认快照，最多15,000,000 UTF-8字节，返回只读结果及输入revision；不返回任务副本、不改变确认/完成状态、不保存服务端清单，不调用Dify或其他模型。`GET /api/health`新增`bounded_planning_v1`，前端在提交排程快照前核验此能力；旧服务不会被静默降级使用。服务进程必须重新加载后才具备此能力，代码修改不等于运行中已升级。

## 范围和语义

最多40个未完成事项，从reference_time到最晚有效截止或固定结束不超过31天；最多4096个时段。支持flexible、fixed、milestone，不支持自动从visit_window中选取时间。所有仍在清单中的可调整事项都纳入，不自动放弃低优先级事项；must_do/priority影响排序，不代表可以静默删除。

关键字段、非空earliest_start_at/depends_on必须确认，草稿和未核对提醒阻止排程。未知空闲不当作全天空闲或零分钟；用户确认空数组才是零空闲。取消的前置事项不视为完成，已完成前置则作为满足处理；这依赖用户更新的状态，并不声称已经核验现实完成记录。

flexible使用正整数剩余分钟，安排总时长必须恰好等于剩余量。不可拆分工作只放入一段；可拆分工作的每段，包括尾段，都必须达到确认的min_block_minutes。固定活动保持原时段，正在进行的活动只展示reference_time后的占用；已结束但仍活跃的固定活动要求核对状态，不滚动日期。milestone在deadline_at为零时长节点，不代替准备工作。前置事项须完整结束后才可开始后继，不能把准备任务放到活动开始之后。固定活动另附deadline或非flexible另附earliest_start的含义暂不支持，显式说明而非忽略。

区间按半开边界处理，相邻不重叠；重复空闲合并，固定占用并集扣除。内部用整数微秒保存时间差，不能把小数容量四舍五入成额外整分钟。路程、转场、休息、未录入工作均由用户在空闲/固定占用里预留，不由算法凭空补齐。

## 方法与独立校验

排程器先做输入与必要容量检查，按前置图逆向传播完成上界，再依次尝试截止优先、窗口余量优先、长工作优先和个人优先级排序。放置后从空闲扣除工作块；拆分尾块过短时缩小前块，避免把尾段要求偷偷放松。四次均失败只表示未找到，不证明无解、不保证最优。

`schedule_validator.py`重新走原始空闲区间、计算实际工作量、检查所有占用、原固定时段、截止、最早开始、连续块和前置顺序。它不调用排程器、不使用放置或空档扣除函数；共用部分仅为输入资格契约、结构校验和时间解析。任一校验失败则隐藏整个候选，不公开部分排好的时间表冒充成功。前端额外核验版本、revision、完整任务覆盖、总工时和校验声明，异常结果不显示成功。

## 响应

schema_version为1（这是排程结果版本，请求快照仍是2）。字段为revision、status、horizon、schedule、validation、issues、conflicts、capacity_checks、warnings、limitations、algorithm。schedule各行严格为task_id、kind（work/fixed/milestone）、start、end。algorithm声明bounded_greedy_v1及attempts/max_attempts，成功时附strategy。

| status | 含义 |
| --- | --- |
| feasible_found | 全部活跃事项有安排且独立校验通过 |
| nothing_to_schedule | 没有活跃事项，空安排校验通过 |
| information_needed | 草稿、缺字段、状态或前置等需核对 |
| unsupported | 超过数量/跨度或存在未支持条件 |
| conflicts_detected | 已发现可说明的必要条件冲突，不返回安排 |
| not_found | 四种排序未找到完整安排，不断言无解 |
| validation_failed | 内部候选未通过独立校验，候选已隐藏 |

除前两种通过状态外schedule均为空。结构错误HTTP400，超限HTTP413。已有`/api/v2/calculate`仍只做必要容量检查，它的no_conflict_detected不能改写为具体排程成功。

## 验证边界

自动检查包含实际临时HTTP服务、前后端契约交接、独立校验篡改、精确时长及异步响应淘汰。另用80组小规模15分钟格点穷举构造可行见证，检查有见证时不会误报已证明冲突；未穷举到不等于连续时间无解。所有数据为合成开发数据，不是用户实测效果或全场景可靠性证明。浏览器渲染、键盘和手机实操尚待用户验证；没有通过其他浏览器接口绕过已保存的自动访问拒绝。
